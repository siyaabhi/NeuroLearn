# NeuroLearn
An assistive Learning platform for Neurodiverse kids
NeuroLearn is a personalized assistive learning platform designed for children with ADHD, Dyslexia and Dyscalculia.  
The system provides interactive lessons, educational games and a calm zone tailored to each child's needs.
## Features
- Personalized learning based on condition 
- Interactive lessons and educational games
- Calm zone with focus tools,relaxation activities and games
- Secure login & signup system
  ## Technologies Used
- HTML
- CSS / Tailwind
- JavaScript
- PHP
- MySQL (Database)
- XAMPP (Apache + MySQL Local Server)
  ## How to Run
1. Start Apache and MySQL in XAMPP
2. Move project to htdocs folder
3. Import database in phpMyAdmin
4. Run http://localhost/neurolearn/
