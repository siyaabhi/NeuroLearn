# NeuroLearn  
An Assistive Learning Platform for Neurodiverse Children  

NeuroLearn is a personalized assistive learning platform designed to support children with **ADHD, Dyslexia, and Dyscalculia**. The system provides adaptive learning experiences through interactive lessons, educational games, and a calming environment tailored to each child's unique needs.

---

## Features
- Personalized learning based on cognitive condition  
- Interactive lessons and educational games  
- Calm Zone with focus tools, breathing exercises, and relaxation activities  
- Secure Login & Signup system  
- Progress tracking and engagement-based learning  
- Child-friendly UI with accessible design  

---

## How to Run Locally

1. Install and open **XAMPP**
2. Start **Apache** and **MySQL**
3. Move the project folder to:
   ```
   C:\xampp\htdocs\
   ```
4. Import the database using **phpMyAdmin**
5. Open browser and run:
   ```
   http://localhost/neurolearn/
   ```
